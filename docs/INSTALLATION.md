# Calculus installieren

Calculus läuft im Browser und kann auf dem Startbildschirm oder Desktop installiert werden. Eine Installation ist optional; die Website funktioniert auch ohne sie.

- **Android (Chrome):** Calculus über `https://hasta-home.com/Calculus/` öffnen und auf „App installieren“ tippen. Alternativ im Browsermenü „App installieren“ oder „Zum Startbildschirm hinzufügen“ wählen.
- **iPhone/iPad (Safari):** Seite in Safari öffnen, auf „Teilen“ tippen und „Zum Home-Bildschirm“ wählen. Andere iOS-Browser bieten diese Funktion je nach Version eventuell nicht an.
- **Computer (Chrome oder Edge):** Seite öffnen und das Installationssymbol in der Adressleiste wählen. Falls es nicht erscheint, das Browsermenü öffnen und „Calculus installieren“ wählen.

Nach der Installation lässt sich Calculus wie eine normale App über das Symbol starten. Zum Speichern von Ergebnissen wird eine Internetverbindung benötigt.
